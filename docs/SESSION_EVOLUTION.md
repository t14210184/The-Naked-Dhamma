# 2026-10-19：從經文報告到大眾互動網站

**性質**：依本次可見對話整理的歷程，不是逐字聊天匯出，不包含未留存的中間檔或模型隱藏推理。

1. **文獻啟動**：要求巴利《小業分別經》《大業分別經》、漢譯平行經、藏譯與大乘相關內容共同對照；反對把前世業報寫成銀行存款、欠債、固定排隊演算法。
2. **第一個 HTML**：國中生版完成，但重要的七組和四格並未直接以讀者預期的互動圖卡可見。使用者以 iPhone 截圖指出不可用。
3. **深色大字版**：七組圖卡與四格常駐、字體放大、手機優先；使用者再指出過多「圖卡已呈現」等工程語、缺乏一般社會大眾生活情境。
4. **有限視角版**：將《大業分別經》從四格善惡結果提升為「親眼所見不等於全貌」、井底之蛙與盲人摸象；點甲、乙卻要往下找解說的 UI 仍不直覺。
5. **原典語意改正**：請教對象不能僅稱「有經驗的人」，須有懂得善惡、修行、長遠苦樂的德行與智慧；加入《沙門果經》的特殊觀察背景、《大業分別經》的推論限制及巴利《指鬘經》石擊故事。
6. **不點就能讀**：使用者指出長者不見得知道卡片能展開，改成四格、七類及十善直接顯示所有關鍵說明，互動只是輔助。
7. **EBT 文獻分層**：納入阿育王石刻、犍陀羅殘卷、巴漢文本異同、後期註釋；指鬘、大目犍連、頻婆娑羅王及摩利迦王后要分清傳承記載與獨立考古確證。使用者指出正文變成學術論文，阻擋大眾閱讀。
8. **故事化遊戲**：首頁改為生活中的反常結果、視野挑戰、鹽水互動與人生選擇，原典放頁尾。但抽象井圖、宗教預設、過度概括故事情節仍被使用者指出。
9. **最新《你看見的，就是全部嗎？》**：具體井底青蛙／山河插畫、先玩再求證、中立敘事、慈心與語言觀察、完整頁尾原典連結，保留深色大字及腳本停用下可閱讀。
10. **升級 GitHub**：使用者提供 `t14210184/The-Naked-Dhamma` 及四個長期模組、全版本歸檔、開源貢獻規劃、Pages 公開展示要求。實際部署須另用 GitHub Pages 來源與公開網址讀回確認。

## 跨版本始終要保留

不曲解經文、不讓人因無宗教背景而排斥；圖解不能抽象難解；不把後期義註當作佛陀原話；區分科學可驗證與傳承記載；一般人阿公阿嬤也懂、長者不須猜哪裡可點；來源與專業術語在頁尾；真實網站經過公網讀回後才稱上線。
