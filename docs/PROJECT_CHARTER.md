# 專案使命與界線

**The Naked Dhamma｜看見更多**：以早期佛教文獻（EBTs）及巴利、漢譯等傳承的對照，啟發一般人觀察身心經驗、反省認知偏差，並由互動體驗通往可查證的原典。

**入口原則**：先故事與遊戲，再自由思考，最後才讀研究證據；不預設宗教信仰。不勸募、不販售消業、不強迫禪修、不以「我有科學根據」掩蓋尚未證實的主張。

**四個方向**：①故事體驗館（最新網站已具備首篇）；②可自願參與、可退出的呼吸與感受觀察；③緣起與五蘊的教學機制圖；④考古、早期文獻與後期註釋的交叉閱讀。

**真實性**：早期平行經支持某些教導較早流傳，並不保證逐字出於歷史佛陀。阿育王石刻與犍陀羅殘卷是重要實物證據，但不可能自動證成每一則人物故事。可親身察覺情緒、呼吸、念頭的變化，不等於已以現代科學驗證輪迴與業異熟。

**古今映射限制**：四聖諦不是現代醫學臨床診斷；涅槃不是熱力學熵減；五蘊不是五個腦部硬體模組；十二緣起也不是單一的條件反射迴路。可以使用類比，但必須顯示「這是為協助理解的現代比喻」。

**內容安全**：不用先前業行責怪病人、失業者與受害者；不以神通或來世預測取代就醫與現實救助。冥想模組不宣稱治療效果。
