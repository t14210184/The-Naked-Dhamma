### 辨別原典、義註與現代推論

- **DN 1〈有邊無邊〉第三種**：原文描述「上下有限、橫向無邊」的感知經驗；與某些後人反方向的轉述不同。參見[巴利原典](https://www.dhammatalks.org/suttas/DN/DN01.html)。
- **DN 1〈現法涅槃〉**：五種意見含一種感官享樂論與四種禪定論；不能說是「四種現法涅槃」。
- **Ud 6.4／《長阿含》卷19**：譬喻可用來說明局部認識，不表示早期文獻已證明現代腦科學的所有認知偏誤理論。
- **AN 3.65／MA 16**：兩者的教導方式存在明顯差異，尤其「不要只憑傳統、論證、師長名望」十條清單不能硬塞入漢譯本。
- **MN 29**：不宜說只要有特殊境界、別人承認，就等於究竟的智慧；它直接批評因成就而抬高自己、貶低他人、停止探究。
- **驗證界線**：上述宗教性的神通、梵天、六道等故事在文本中確實存在，不代表考古或現代科學已獨立證實其內容。網站只將其呈現為可核對的古代傳承材料，並提供讀者自己觀察、比較、質疑的入口。
