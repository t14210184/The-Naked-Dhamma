# 給所有人的互動介面原則

## 核心體驗

「看見意想不到的情況 → 選擇 → 發現視野有限 → 嘗試另一種理解 → 自行看原典」，**首頁不先放經號、術語或學術論文**。

## 本次對話的永久保留要求

- 預設深色、大字、高對比，字級能放大；以手機、長者和不熟悉網頁操作的人優先。
- **不點也能讀完**：四種情況、七類人生差異、十項倫理提醒都不藏在必須互動才能展開的區塊。
- 互動需有明顯提示、按鈕與立即可見的回饋；不設「只看甲」「只看乙」而讓使用者不知道內容出現在哪裡。
- 井底之蛙一定要有具象的蛙、井壁、井口小天空，以及井外廣闊山河，不能只拿抽象圖形。
- 正文用阿公阿嬤也懂的日常話；「沙門、梵志」、經號與版本異文可留頁尾並加註解。
- 不把處境不佳的人說成前世欠債；現代例子從真正常見的職場、鄰里、親友與網路訊息開始。
- 不把「邪淫」誤翻成任何性行為必然傷害別人；也不可把綺語直譯成不知所云的「無益失當的話」而沒有例子。
- 真正修習的方法優先取自有原典根據的慈心、呼吸觀察、反省動機與言語，而非編造「償還業力」的儀式。
- 「文字來自原典」與「互動練習是現代編排」明顯分層；頁尾提供具體經名、章節與連結。

- 測 320／375／390／430／768／1440px、放大字級、iOS 真機、水平溢出、按鈕遮字、鍵盤導航、低動態偏好。

- 每個點擊應在**同畫面**看到可辨別的回饋；不靠隱晦手勢才能進入下一段。
- 生活練習不得宣稱科學或醫療效果；離線閱讀主文可行，外部來源需網路。
