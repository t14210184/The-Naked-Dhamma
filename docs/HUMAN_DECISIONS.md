# 需要專案持有人決定的事項

此清單不封鎖已批准的文件與網站匯入。它只記錄真正需要 Human 明確決定的範圍。

- **正式開源授權（法律性決定）**：程式碼可評估 MIT 或 Apache-2.0；原創文章／插畫可評估 CC BY 4.0 或 CC BY-SA 4.0。兩類授權的責任與著作權聲明要分開；須確認插畫生成使用權與所有第三方素材來源。使用者尚未指定，不擅自發 LICENSE。
- **GitHub Pages 發布來源**：Human 已明確要求公開網站；若目前連線工具無法操作 GitHub Settings → Pages，需 Human 在 Pages 設定選 GitHub Actions，之後可由既有部署流程繼續。
- **專案英文／中文對外文案**：可以研究「心智現象學」「認知機制」語感，但不得將古代教法宣稱為已有當代實驗支持的自然科學定律。
- **未來分析資料或網站帳號**：若要加追蹤、回傳個人感受或第三方服務，先重新確認同意範圍、隱私政策與費用；第一版不蒐集。
