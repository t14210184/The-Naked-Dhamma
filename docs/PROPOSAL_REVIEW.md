# 提案中的必要修正：保留吸引力，不以新名詞代替迷信

- 「原始佛法＝西元前五世紀的實證認知科學」：可作宣傳問題句，不能當歷史既成事實。年代有爭議；古代內觀是一種經驗方法，並不等於近代控制實驗、儀器觀察與統計反駁程序。
- 「考古發現證明釋迦牟尼根本沒教拜神」：單靠阿育王石刻或古抄本做不到此排除性結論。只能說特定實物反映當時某些教法與社會存在。
- 「不同語言一致＝佛陀最原始教導」：文獻交集是較早共同流傳的證據，不保證逐字、事件及每種解釋皆早至佛陀本人。
- 「苦＝熱力學熵增、涅槃＝系統平衡」：純類比，不能以物理學等式作保證；各派對涅槃有精細差異。
- 「無我＝大腦沒有中央 CPU、五蘊＝五種神經模組」：直觀但不等價，且五蘊在經文中是觀察分類而非解剖模型。
- 「十二因緣＝接觸產生條件反射」：只涵蓋某些心理環節；不可省略其他支而聲稱完整解釋輪迴緣起。
- 「ACT/MBSR 完全源於早期佛教」：不同療法有多重歷史來源與重構，不宜寫成唯一源頭。
- 「只收早期阿含／尼柯耶，不准一切後期故事」：網站研究以早期為主，但晚出材料可保留清晰標示，以便讀者分辨流傳過程。
- 「凡可內觀即可自證輪迴」：內觀可提供第一人稱身心資料；關於他人的業異熟與過去生，不能當成現代可普遍重複驗證的結果。

結論：對外內容要在「親身實驗自己可觀察的部分」「古代教導及其歷史流傳」「現代科學的特定實驗證據」三者之間畫出清楚邊界。
