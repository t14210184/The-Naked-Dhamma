# 路線圖：先有吸引力，再加可驗證深度

此處列規劃而非已接受完成項；GitHub Issue／PR 作為後續工作協作來源，不另建 Task DB。

## 第 0 步：可公開體驗的第一個版本

內容：把《你看見的，就是全部嗎？》放在 `index.html`，保存八份對話歷史版，提供原典頁尾、深色大字、長者可讀主線、具象井圖。以 GitHub Pages Actions 發布與公開網址 HTTP／內容讀回作為 LIVE 驗收。

完成標準：取得正式 Pages 回報的 URL；公開網址返回有效 HTML，標題及主要互動可辨識；有確切部署 commit SHA。若 Pages 未在 Settings 啟用，只標示 blocked，不假稱已上線。

## 第 1 步：故事探索館

針對三個短故事建互動導讀：《箭喻經》（MN 63，避免把整部經簡化成「不問宇宙問題」）、《蛇喻經》（MN 22 的筏喻）、指鬘案例。基莎·瞿曇彌尋芥子故事如果採用，應標示其可核對的傳承與較晚文獻定位，**不能冒稱所有早期平行經共有**。

驗收：各篇有 2–3 個自然互動、長者不互動也能順讀、頁尾逐段證據與「現代比喻」標籤。用匿名本地測試比較完成閱讀率，不預先宣稱提高多少。

## 第 2 步：內修觀察工作台

60 秒自願呼吸觀察與情緒覺察：開始前自評／完成後自評只留使用者裝置，不上傳；支援跳過、停止及無動畫模式。清楚提示每個人感受可能不同，不構成醫療診斷、不暗示療效、不可操作過度換氣。

驗收：鍵盤及手機都能開始／暫停／結束；沒有位置、帳號或健康資訊流出；文字與《念處經》《出入息念經》對應而非假借「古代腦科學已證實」。

## 第 3 步：機制圖

緣起「觸→受→愛→取」僅作**部分片段**的互動示例，旁邊明示十二支與非線性條件脈絡；五蘊拆解用觀察語句而非「物理拆分大腦」。

驗收：每一節標出經文出處、比喻限制、反例與讀者無須先接受的假設。

## 第 4 步：文獻與考古探索室

先做一組可信平行經比較，逐句上色標示共通、差異與缺段；研究史與考古實物另欄展示。禁止用「一致＝佛陀原話」取代史料方法。

## 技術與傳播（非第一階段硬性依賴）

- 優先原生 HTML/CSS/JavaScript＋GitHub Pages；有大量文稿或元件複用需求才評估 Astro 靜態建置，不因潮流導入 Next.js、服務端與大型狀態管理。
- 在有明確版權授權前不大量複製他人經典翻譯或出土文物圖片。
- 發布到 Threads、Medium、Hacker News 等前，準備不誇大科學證據的繁中短篇介紹與可分享頁面預覽。
