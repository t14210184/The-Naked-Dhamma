為什麼做壞事的人有時還過得很好？為什麼好人也會遇到困難？佛陀的回答，比「好人一定有好報」更細緻。

01

先搞懂：「業」是什麼？

不是神明記分，更不是固定不變的命運

在佛教裡，業不是神祕的分數，而是跟意圖密切相關的身體、語言與心理行為；業果是這些行為在相關條件下可能成熟的結果。

🧠

心裡怎麼想

明知會傷害別人，卻故意這樣做，與意外發生的事不同。

🗣

嘴巴怎麼說

誠實、辱罵、散播謠言，都能影響自己與別人。

🤲

身體怎麼做

保護、偷拿、傷害、布施，都是應認真看待的行為。

經典的教導行為有善惡差別，會有相應的因果意義；現在的修行也重要。
不能亂推論生病的人不是「罪有應得」；富裕的人也不是「功德第一名」。

先認識證據：「巴利 MN 135 與漢譯《鸚鵡經》」是直接平行經；藏譯 Toh 338 是內容相關的另一經本；大乘《十善業道經》呈現相近的倫理架構。這些不應一律說成逐字相同。

02

《小業分別經》：七種人生差異

巴利 MN 135 ⇄ 漢譯《鸚鵡經》170；藏譯 Toh 338 保留相關分類

年輕人須婆問佛陀：為什麼有些人長壽，有些人短命；有些人富足，有些人貧窮？佛陀以七組相關善惡行為與果報回答。這些說法是經中討論的業果關係，不能拿任何人目前的遭遇，判定他過去一定做過什麼。

每一種選擇，都值得仔細思考向下閱讀七種差異，點開各項可看到經典意思與日常實踐。
01/07
七種人生差異

壽命

相關不善業殺害生命↓經中所述：短命
相關善業遠離殺生、愛護生命↓經中所述：長壽
點開看：經文、生活例子與提醒 ⌄

經典教導《中阿含》170《鸚鵡經》說「離殺斷殺」，具慈悲心；MN 135 也將不殺生與長壽相聯繫。

生活中的實踐遇見受困的小動物，在安全可行時協助牠脫困，不把生命當作取樂的工具。

不可誤用：不能因某人早逝，就認定他前世殺害過生命。

參考經文：巴利 MN 135 ↗ · 漢譯《鸚鵡經》 ↗

02/07
七種人生差異

健康

相關不善業以拳、石、棍棒傷害他人↓經中所述：多病
相關善業不毆打、不虐待他人↓經中所述：少病
點開看：經文、生活例子與提醒 ⌄

經典教導《鸚鵡經》談「不觸嬈眾生」；MN 135 也將不傷害他人與健康的果報相聯繫。

生活中的實踐發現有人遭到暴力對待時，不跟著欺負；在自身安全的前提下求助或通報。

不可誤用：生病不是道德失敗；醫療、遺傳及環境等原因需要認真處理。

參考經文：巴利 MN 135 ↗ · 漢譯《鸚鵡經》 ↗

03/07
七種人生差異

容貌

相關不善業容易瞋怒、怨恨↓經中所述：不端正
相關善業減少瞋怒、不懷怨恨↓經中所述：端正
點開看：經文、生活例子與提醒 ⌄

經典教導《鸚鵡經》與 MN 135 都談到容易發怒、懷恨，與容貌差異的相關業果。

生活中的實踐被批評時先辨別內容，練習不以辱罵或報復回應。

不可誤用：不能用外貌評定誰比較善良，更不能歧視外貌不同的人。

參考經文：巴利 MN 135 ↗ · 漢譯《鸚鵡經》 ↗

04/07
七種人生差異

威德／影響力

相關不善業嫉妒別人的名譽與尊重↓經中所述：無威德
相關善業不嫉妒，能隨喜他人↓經中所述：有威德
點開看：經文、生活例子與提醒 ⌄

經典教導巴利 MN 135 與漢譯《鸚鵡經》都列出嫉妒與「威德」相關的果報；經中所說的「威德」不是單憑金錢或職位高低判定。

生活中的實踐親友或同事獲得肯定時，能真誠祝賀，不因嫉妒而貶低或造謠。

不可誤用：有權勢不等於有德；地位還涉及制度、家庭與社會機遇。

參考經文：巴利 MN 135 ↗ · 漢譯《鸚鵡經》 ↗

05/07
七種人生差異

財富

相關不善業不願布施、吝於分享↓經中所述：貧乏
相關善業布施、願意援助↓經中所述：富足
點開看：經文、生活例子與提醒 ⌄

經典教導MN 135 著重是否向修行人布施生活所需；漢譯有相應內容。藏譯 Toh 338 有更廣的業因說明，細節不全相同。

生活中的實踐量力分享金錢、食物、時間或專業，扶助遇到困難的人，不以捐款換取保證。

不可誤用：不是付錢就能買富貴，更不能認為窮人一定是前世吝嗇。

參考經文：巴利 MN 135 ↗ · 漢譯《鸚鵡經》 ↗

06/07
七種人生差異

出身／社會身分

相關不善業傲慢，不尊重應尊敬的人↓經中所述：較低出身
相關善業謙卑，尊重他人↓經中所述：較高出身
點開看：經文、生活例子與提醒 ⌄

經典教導《鸚鵡經》及 MN 135 使用古印度社會的「出身高低」語境，討論傲慢、謙遜及尊重。

生活中的實踐尊重清潔人員、店員、長者與工作夥伴，不因職位、收入或家庭背景而輕視誰。

不可誤用：「出身高低」反映古印度階級語境，不可拿來支持今日階級歧視。

參考經文：巴利 MN 135 ↗ · 漢譯《鸚鵡經》 ↗

07/07
七種人生差異

智慧

相關不善業不請教善惡、是非之理↓經中所述：缺乏智慧
相關善業請教有智慧者、思考實踐↓經中所述：有智慧
點開看：經文、生活例子與提醒 ⌄

經典教導兩部平行經都勸人向有智慧者請教：何者善？何者不善？何者有長遠利益？

生活中的實踐遇到難解的事先查證，向有經驗的人請教，也問問自己做的事是否會傷害他人。

不可誤用：學習障礙及教育資源差異也影響表現；不應以成績評斷前世。

參考經文：巴利 MN 135 ↗ · 漢譯《鸚鵡經》 ↗

經文界線：這七組是經典對業與果的宗教性說明，不是用外貌、疾病或財富推斷某人前世的科學公式。不可據此責怪受苦或弱勢的人。

03

《大業分別經》：看見一角，不等於全部

巴利 MN 136 ⇄ 漢譯《中阿含》171《分別大業經》

這部經最值得學習的，不只是四種善惡行為與果報的組合，而是不要像井底之蛙，把自己看見的一小片天空，當成整個世界。

井底之蛙的提醒

看到的可以是真的，結論卻可能是錯的。

一隻青蛙確實看見了井口的天空，可是牠沒看到的天空仍然存在。經中有修行人觀察到某種業行與死後去處，便斷言「所有人都一定如此；不一樣的說法都是錯的。」佛陀不接受這種以偏概全的判斷。

有些事實是真的，不代表你已知道全部原因。

① 看見一例某個觀察可能屬實
→
② 擴大成全部「所有人必定如此」
→
③ 誤判別人否定善惡、責怪受苦者

以下四種情況是經中關於生前業行與死後投生去處的討論，不是這一生薪水、健康或財富的統計資料。生活中的例子，只用來幫助理解「如何避免以偏概全」。

換個視角：只看一例，你會下什麼結論？

先選「只看甲、乙、丙、丁」中的任一種，再選「看全貌」，感受只見局部與對照全部有何不同。

放眼全貌：四種都可能被經文討論。看見其中一例，不等於知道所有人的結局；正確的觀察，還需要正確的推理。

井底的一眼：看到「不善行 → 惡趣」，這一例可以是真的。問題出在把「有這種情況」說成「所有人都只會這樣」。

井底的一眼：看到「不善行 → 善趣」，不能推論作惡沒有後果。有限的所見，不能抹去未見的業因與條件。

井底的一眼：看到「善行 → 善趣」，不能推論所有好人都立刻得到同樣的善報。這是以一例取代全貌。

井底的一眼：看到「善行 → 惡趣」，不能否定行善的價值，也不能把受苦當成別人應得的懲罰。

情況甲經中記載的可能情況

不善行 → 惡趣

生前造不善業
→
死後投生惡趣

所見的一角有人生前殺生、欺騙、傷害他人，死後投生惡趣。

看見這一例，容易想錯什麼？⌄
草率的結論

「所以，每個造惡的人，死後一定立刻落入惡趣；我看到的就是唯一規則。」

錯在哪裡？

把某個真實例子擴大成所有人的固定結局，忽略其他時間造的業以及成熟條件。

可能造成的傷害

容易武斷地斷言他人命運，甚至用自己的有限所見審判別人。

更合乎經義的理解

這種情況可以成立，但不能因此排除另外三種情況。

生活類比（不是來世的證據）：看見一位違法者被依法處罰，不代表所有違法事件都會在相同時間得到相同結果。

情況乙經中記載的可能情況

不善行 → 善趣

生前造不善業
→
死後投生善趣

所見的一角有人生前做了許多不善行為，死後卻投生善趣。

看見這一例，容易想錯什麼？⌄
草率的結論

「既然這個人能去善趣，說明作惡沒關係；根本沒有惡業的果報！」

錯在哪裡？

看見一個不符合直覺的結果，就否定整個善惡因果，而沒有看見其他業與條件。

可能造成的傷害

可能把暫時得利誤認成作惡值得模仿，放任傷害與剝削。

更合乎經義的理解

經文提出過去或其他時期的善業、臨終正見等可能；看不見全部條件，不能替任何人指定確切原因。

生活類比（不是來世的證據）：看見靠欺騙獲利的人仍住豪宅，不能說騙人就是成功之道；也不能猜定他前世有多少「善業存款」。

情況丙經中記載的可能情況

善行 → 善趣

生前修善行
→
死後投生善趣

所見的一角有人遠離傷害、守持善行，死後投生善趣。

看見這一例，容易想錯什麼？⌄
草率的結論

「所以只要做好事，每一個人就必定立刻得到同樣的好結果。」

錯在哪裡？

看見善行與善趣相符，便誤以為所有善報都必然在同一時間、以同一方式出現。

可能造成的傷害

容易要求善良的人必須永遠順遂；一旦有人遭遇困難，反而責怪對方「不夠善良」。

更合乎經義的理解

善行值得培養，但不能把一個合乎期待的例子當作掌握了所有業報規則。

生活類比（不是來世的證據）：一位熱心公益者生活順遂，不表示每位助人者都必然健康、富裕，更不能倒過來指責受苦者。

情況丁經中記載的可能情況

善行 → 惡趣

生前修善行
→
死後投生惡趣

所見的一角有人生前持守善行，死後卻投生惡趣。

看見這一例，容易想錯什麼？⌄
草率的結論

「連好人也有壞結果，行善根本沒有意義，何必善待別人？」

錯在哪裡？

只看見一段不利結果，就把善行的價值一筆勾銷，忽略其他業與條件。

可能造成的傷害

容易對善良失去信心、對他人冷漠，甚至把別人的苦難當成嘲笑或推卸責任的理由。

更合乎經義的理解

經文提及其他時期的不善業、臨終邪見等可能；不能憑單一所見斷言善行無果。

生活類比（不是來世的證據）：一位長期照顧弱勢的人罹患重病，不能因此說關懷沒有價值，更不能說他受苦是應得的。

注意：單看一個真實例子，不等於它是假的；錯在把個例當成所有人的共同規則。經文仍肯定善惡行為及其業果，並非說善惡沒有差別。
◎

真正的智慧，是承認自己還沒看見全部

《大業分別經》提醒：即使自認親眼所見，也應分清楚「我確實看見什麼」和「我自行推斷了什麼」。真正重要的不是先證明自己永遠正確，而是留意還有哪些因緣尚未明白。

放進現代生活：看見好人受苦，先幫助他，不要揣測他的前世；看到作惡者暫時得利，也不必把作惡當成值得模仿的路。

對讀經文：巴利 MN 136《大業分別經》 ↗ · 漢譯《中阿含》171 ↗

巴漢平行經都保留四種情況；本文的「井底之蛙」是協助理解有限觀察的現代比喻，並非經文原有故事。

04

《鹽喻經》：同一把鹽，兩種結果

AN 3.100 ⇄ 《中阿含》11《鹽喻經》

佛陀用「一小把鹽」說明：同類的小惡業，在不同修養與條件下，結果可能有輕重差異。

互動操作：鹽巴量固定，只切換水量。

一杯水：鹽巴相對集中，可能鹹得不能喝。

一條大河：同一把鹽被大量水稀釋，不會讓整條河變得那麼鹹。

經典意思經典談的是小惡業在不同條件中的果報輕重，並重視修身、修戒、修心、修慧。

教育應用以前做錯過的事不必當成命運已定；現在停止傷害、承擔責任、培養智慧，仍有意義。

絕不能誤讀：這不是說「做十件好事就能抵銷一次重罪」，也不代表捐錢即可清掉全部業報。比喻中的鹽不是貨幣，佛教也沒有統一的業力存款表。

經文：巴利 AN 3.100 ↗ · 漢譯《鹽喻經》 ↗

05

十善業：身 3、語 4、心 3

早期佛典與大乘經典都保留相近的十善倫理架構

十善不只是避免傷害，也是學習如何待人、說話、管理情緒。可以依身體、語言、心念分別閱讀。

🫱

身體 · 03 項

以行動不傷害人

01不殺生殺生、傷害生命＋

經典方向遠離：殺生、傷害生命；培養：保護生命，避免無故殺害。

今天試試看見受傷動物時，能在安全情況下尋求適當協助。

02不偷盜偷拿不是自己的東西＋

經典方向遠離：偷拿不是自己的東西；培養：尊重別人的財物。

今天試試撿到手機或錢包，設法交還失主，不占為己有。

03遠離不當性行為傷害他人的性行為＋

經典方向遠離：傷害他人的性行為；培養：尊重界線與承諾。

今天試試不強迫、不侵犯，尊重他人身體自主。

🗣️

語言 · 04 項

說話也會帶來影響

01不妄語說謊、故意欺騙＋

經典方向遠離：說謊、故意欺騙；培養：講真話。

今天試試不為了利益捏造消息，也不傳播明知不實的指控。

02不離間挑撥彼此仇視＋

經典方向遠離：挑撥彼此仇視；培養：說促進和睦的話。

今天試試親友或同事發生衝突時，不故意挑撥、煽風點火。

03不惡口用話語羞辱傷害＋

經典方向遠離：用話語羞辱傷害；培養：語氣溫和而真實。

今天試試就算意見不同，也盡量說理，不辱罵或羞辱對方。

04不綺語無益或不合時宜的言語＋

經典方向遠離：無益或不合時宜的言語；培養：說有意義、合時宜的話。

06

兩個重要提醒：動機與受苦

AN 6.63 談意圖；SN 36.21 反對「凡受苦都是前世業」

同樣碰壞別人的東西，動機一樣嗎？

甲倒車時不小心碰倒停放的機車；乙因為報復，故意把機車推倒。財物同樣受損，兩人的意圖卻不同。

看經典怎麼分辨 ⌄

經典方向AN 6.63 說明意圖是業的重要核心。故意傷害與無意失手，不宜在倫理上當成同一件事。

生活中的實踐不論是否故意，都應處理損害；倫理判斷還需要考慮意圖、責任與補救。

有人生病，可以說是他前世做錯事嗎？

不能。疾病可能涉及感染、遺傳、意外、環境、照護條件等現實原因。

看經典怎麼提醒 ⌄

經典方向SN 36.21 批評把一切感受都歸因於過去業的說法。

生活中的實踐先協助就醫、陪伴及處理眼前困難，而不是替病人猜前世。

把這些道理用在待人處事上

不以財富衡量人格、不以病痛指責當事人、不因別人的成功心生嫉妒；遇到傷害就停止，遇到受苦就幫忙，遇到不懂就求證。

07

生活情境：你會怎麼判斷？

先自己想一想，再點開查看理由。這些是現代教學案例。

情境 A｜朋友升遷了

朋友或同事獲得升遷，你心裡不平衡。該散播他靠關係的傳言，還是先查明情況、真誠祝福？

點開思考與經典連結 ⌄

較適當：先承認自己有嫉妒心，但不要因此傷害別人；可以道賀，再檢視自己想努力的方向。

相關經典MN 135 與《鸚鵡經》都有嫉妒、威德相關的業果教導。

情境 B｜看到有錢人欺負人

有人仗勢欺人卻過得富裕，這能證明善惡因果是假的嗎？

點開思考與經典連結 ⌄

不能。也不能反過來確定他的前世善業餘額。僅憑眼前一個結果，不能認定所有業果機制。

相關經典MN 136 和《分別大業經》提醒不要以偏概全。

情境 C｜有人宣稱付錢就能消災

對方保證付一筆錢，前世所有惡業就會完全清零。能當成共同佛教經義嗎？

點開思考與經典連結 ⌄

不能。這些共同經典未建立「付錢保證消業」的機械公式。布施與改正行為有其宗教意義，但不能當成商業保證。

相關經典《鹽喻經》重視修身、修戒、修心、修慧，而不是購買清帳服務。

情境 D｜網路流傳指控

社群大量轉傳某位店家或鄰居的負面傳言，事實尚未查明。你要跟著轉發嗎？

點開思考與經典連結 ⌄

先查證再說話。不散播自己不知道真假的消息，特別是可能造成嚴重傷害時。

相關經典十善業所說的遠離妄語、離間語與惡口。
