# The Naked Dhamma｜看見更多

**從生活中的判斷開始，親自觀察，再回到可查證的早期文獻。**

這是一個繁體中文優先、免費閱讀、適合手機與年長讀者的互動探索專案。第一個作品是《你看見的，就是全部嗎？》：以井底之蛙、四種看似矛盾的結果、鹽水比喻與生活練習，呈現「觀察到部分真相，不等於知道全部原因」的問題。

## 專案定位

- **優先提供好讀、好玩的體驗**：不要求讀者有宗教信仰或熟悉典籍。深色、大字、明顯的操作提示；即使不點互動圖卡，也能連續閱讀主要內容。
- **文獻可追溯**：優先比對巴利《尼柯耶》、漢譯《阿含經》及其他早期傳承；指出平行、異文及後來註釋。正文用白話；精確出處放在「閱讀更多」。
- **不假借科學背書**：第一人稱體驗可用來認識自己的身心現象，但不等於已由現代科學證成來世業報等主張。早期文獻與現代認知科學是可比較的不同研究對象，不是同一套已驗證的理論。
- **獨立思辨**：反對從單一觀察武斷推定所有個案，亦不把歷史佛陀的逐字言論、故事人物遭遇或年代當成未經驗證的歷史事實。

## 四個逐步發展的方向

1. **故事探索**：生活情境、視野挑戰、可直接閱讀的白話圖解。
2. **身心觀察**：自願參與的短時呼吸／感受記錄；不蒐集私人健康資料，亦不宣稱療效。
3. **機制地圖**：將早期經文談到的經驗過程製作成可操作的輔助模型，明確註明哪些是比喻。
4. **證據探索**：早期平行經對勘、譯文差異、經典記載與考古材料分層，公開更正錯誤。
